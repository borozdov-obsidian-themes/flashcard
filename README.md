# Borozdov Flashcard

A theme from the Borozdov collection. Two faces — light **Midterm**, a colour-coded study
desk on chalk white, and dark **Cram**, the same desk the night before the exam. Indigo ink,
iris pill buttons and callouts framed like flashcards in cyan, pink, violet and peach.

![Borozdov Flashcard in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/flashcard/main/screenshots/light.png)

![Borozdov Flashcard in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/flashcard/main/screenshots/dark.png)

## Principles

- **Every callout is a flashcard.** A coloured frame with 24px corners carries the title
  around a panel for the text: violet for notes, cyan for tips and what is done, pink for
  questions and examples, peach for warnings, rose for trouble.
- **One iris.** Iris fills the pill buttons, a checked task and the toggle and colours
  links; a lilac wash holds tags, the open file and the highlighter.
- **Indigo ink, never black.** Text in ink charcoal, headings in deep indigo, at weight 600
  at most.
- **A night for cramming.** Cram turns the page a deep study-hall navy with indigo panels;
  the flashcard frames keep their pastels.

## Features

- Light and dark modes, following Settings → Appearance → Base color scheme
- Callouts as flashcards: a coloured frame around a panel for the text
- Pill buttons and tags in iris and lilac
- Tables and code as white cards with a mist frame
- Quiet editing: no focus ring around the note, its title or form fields while you type;
  property names read as labels, not boxed fields
- Text colours meet WCAG contrast on both faces
- The phone layout keeps the same colours and shapes
- No embedded fonts, so the theme stays around 12 KB
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory:** Settings → Appearance → Themes → Manage, search for
**Borozdov Flashcard**, then **Install and use**.

**By hand:** download `manifest.json` and `theme.css` from the [latest
release](https://github.com/borozdov-obsidian-themes/flashcard/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Flashcard/`, then choose Borozdov Flashcard under
Settings → Appearance → Themes.
